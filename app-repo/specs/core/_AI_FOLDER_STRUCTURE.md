# AI Guidance: Folder Structure

This document describes the high-level repository folder layout as it exists today.

## Key folders

- app-repo/src
  - Backend and core server/runtime code.

- app-ui/src
  - Frontend UI code (React/Vite).

- app-repo/config
  - Configuration files and defaults used by the backend/runtime.

- app-repo/specs
  - System specifications and governance documents.

- app-repo/docs/ai
  - AI governance and context routing documents.
